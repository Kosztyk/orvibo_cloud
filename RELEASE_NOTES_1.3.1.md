# ORVIBO Cloud v1.3.1 — HACS publishing readiness

This release prepares ORVIBO Cloud for distribution through HACS.

- Home Assistant Hassfest and HACS validation in GitHub Actions
- Correct HACS display metadata, explicit hub integration classification
- HACS custom-repository installation instructions
- Updated documentation for RF blinds, optional per-blind assumed state,
  restart restoration and expiration
- Packaging checks, changelog and documented verification scope

This is a packaging and documentation update. No changes were made to the
ORVIBO device APIs, account login, binary cloud protocol, TLS communication,
commands or device state logic.
